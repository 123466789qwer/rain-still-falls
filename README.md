# Rain Still Falls: A Distributed Philosophy of Existence

**雨还在下：分布式生存哲学**

*From Zizhi Tongjian to Ultraman — a political philosophy手记 on cages, codes, and being.*

---

## About This Book

This book asks: When every institution claims "this is for your own good," how do you know you are still alive?

The answer: **Become a variable.**

Not a hero. Not a rebel. Not a saint. Just a multi-threaded existence that refuses to be locked into a single-threaded system.
